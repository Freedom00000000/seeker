What a location-phishing page could see

This is an educational demo. Attackers host innocent-looking pages ("see who's nearby", "join the video call", "track your delivery") whose real goal is to make you tap Allow on the browser's location prompt. This page shows exactly what they would learn if you did — so you can recognise and refuse the real thing.

Nothing here is sent anywhere. This page contains no network code at all. Everything below is read and shown only inside your own browser, and is gone when you reload. A real attacker's page would quietly transmit all of it instead.

How to protect yourself

  • Treat an unexpected location prompt like a password prompt — ask why this page needs it, and deny by default.
  • Legitimate "nearby" features still work if you deny and type your city; a tracker does not.
  • Prefer "Allow once" over "Allow while visiting".
  • Review and revoke site location permissions periodically:
    Chrome: chrome://settings/content/location · Firefox: Settings → Privacy → Permissions → Location · Safari/iOS & Android: per-site browser settings + OS location settings.
  • Be suspicious of look-alike domains and links behind URL shorteners or tunneling services.
